# 🛒 Product Listing Website (Search & Pagination)

A responsive product listing web application built using **HTML, CSS, and JavaScript**.  
The app fetches products from an external API and provides **search filtering**, **pagination**, and a **modern UI with navbar**.

---

## 🚀 Features
- Fetch products from **DummyJSON API**
- Search products by title
- Pagination with **Prev / Next**
- Pagination buttons auto-disable & blur at limits
- Responsive product grid layout
- Clean navbar with search box
- Works smoothly on desktop & mobile

---

## 🧰 Tech Stack
- HTML5  
- CSS3 (Grid, Flexbox)  
- JavaScript (ES6)  
- DummyJSON API

## 🌐 API Used
https://dummyjson.com/products
---

## 🧠 Working Logic
- Products are fetched and stored in an array
- Search filters products based on input
- Pagination displays limited items per page
- Buttons disable automatically on first & last page
- Same layout works for filtered and normal results
